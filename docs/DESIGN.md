# 拾光清理设计约定

采用 UI/UX Pro Max 技能的单列布局、清晰主操作、空状态和触控可达性建议；按中文 Android 工具的实际需要调整配色和字体，不使用其不适合中文的手写字体建议。

- 暖白背景 `#F4F5F0`，墨绿操作色 `#176B55`，深色正文 `#20382D`，辅助正文 `#56665C`。
- 系统中文字体，正文至少 14sp，主要操作至少 48dp，支持系统字体缩放。
- 三个固定入口：总览、清理预览、设置。正常使用页面不出现接口和凭据等开发概念。
- 总览只保留一个主操作，所有统计来自本地实际记录。没有连接或没有扫描时使用真实空状态。
- 清理预览显示文件名、云端位置和候选原因。手动选择后再次确认回收站操作；自动模式单独说明边界。
- 使用自绘矢量照片插画，不读取用户照片装饰页面，不使用网络字体或远程图像。
- 当前版本仅提供浅色主题；保持明暗状态栏、字号和系统边缘区域可读。后续深色主题需另行验收。

## v0.2.0 图标

墨绿 `#173F35` 底色，暖白照片与云朵，鼠尾草绿山形和金色太阳。轻微倾斜的相片体现整理照片的用途，图形不含文字和第三方商标。

Android 桌面采用分离的背景与矢量前景，由系统裁切圆形或圆角；主体缩放至安全区域。Android 13+ 提供单色主题层，通知使用独立的单色资源，不使用实心背景。导出的 [SVG](branding/icon.svg) 与 [PNG](branding/icon.png) 可用于项目介绍。
