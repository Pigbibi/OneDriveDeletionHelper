# 隐私说明

更新日期：2026-09-09。项目维护者：Pigbibi。

PhotoKeep 不提供开发者服务器，不接入开发者广告、统计和崩溃上报。应用由手机直接访问微软登录、Microsoft Graph 以及微软返回的文件下载地址。

## 本地处理

本地记录包括选定目录、文件名、大小、媒体标识、SHA-256、微软账号标识、OneDrive drive/item 标识、候选原因和操作状态。为识别文件移动及相同副本，应用会检查内部存储中系统可见的照片和视频，但只为选择的目录建立新的管理关联。

原文件只在本机计算摘要。申请原始媒体访问权限是为了读取未删减元数据的完整文件字节，不将位置坐标用于定位功能。清理前流式读取云端原文件核对内容，不重新上传照片，不把文件内容、摘要或文件名发送给开发者，也不另存云端照片副本。

记录和内容摘要缓存保存在应用私有目录。云备份和设备迁移均关闭。卸载或清除应用数据会移除这些记录，OneDrive 文件保持原样。

## 微软授权

使用官方 MSAL 进行浏览器登录、授权和令牌管理。应用不接收你的密码，不把令牌和预授权下载链接写入业务记录。微软身份服务处理的信息适用微软的隐私政策。

Graph 的委托 `Files.ReadWrite` 权限包含读写能力，并不是专门的只删除权限。PhotoKeep 业务代码只实现读取、核对和移入回收站，没有上传、覆盖、移动或永久删除接口。

可以在应用设置中断开连接，并在微软账号中撤销应用授权。主动打开网页帮助或项目链接时，系统浏览器会访问相应网站。

## 反馈

通过项目 GitHub Issues 提交反馈时，请自行去除账号、私人照片、文件列表及凭据。不要公开应用私有数据、日志令牌或签名私钥。项目不会要求你公开密码或验证码。
