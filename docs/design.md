# 拾光清理设计约定

采用 UI/UX Pro Max 技能的单列布局、清晰主操作、空状态和触控可达性建议；按中文 Android 工具的实际需要调整配色和字体，不使用其不适合中文的手写字体建议。

- Material 3 色彩角色：冷灰背景 `#F7F8FA`，单一强调色钴蓝 `#2A5B9C`（深色 `#A8C7FA`），正文 `#171C23`，辅助正文 `#454E5B`；危险操作独立使用错误色 `#B42318`（深色 `#F4B4AB`）。
- 形状层级：标签 8dp，卡片与列表组 16dp，主卡片与空状态 28dp，按钮全圆角；底部导航采用 M3 导航栏的胶囊指示器。
- 系统中文字体，正文至少 14sp，主要操作至少 48dp，支持系统字体缩放。
- 三个固定入口：总览、清理预览、设置。正常使用页面不出现接口和凭据等开发概念。
- 总览只保留一个主操作，所有统计来自本地实际记录。没有连接或没有扫描时使用真实空状态。
- 清理预览显示文件名、云端位置和候选原因。手动选择后再次确认回收站操作；自动模式单独说明边界。
- 使用自绘矢量照片插画，不读取用户照片装饰页面，不使用网络字体或远程图像。
- 跟随系统明暗主题，颜色定义在 `values/colors.xml` 与 `values-night/colors.xml`；内置教程与隐私页面通过 `prefers-color-scheme` 同步明暗。

## 应用图标

钴蓝 `#21508F` 底色，白色相片内是浅蓝天空、两座山和暖黄太阳，右下角的浅蓝云朵带对勾，表示照片已在云端核对。图形不含文字和第三方商标，小尺寸下以相片与云朵两个轮廓识别。

Android 桌面采用分离的背景与矢量前景，由系统裁切圆形或圆角；主体缩放至 66dp 安全区域。Android 13+ 提供单色主题层（相框与云朵镂空对勾），通知使用同一单色资源，不使用实心背景。各密度 `mipmap-*/ic_launcher(_round).png` 由同一几何导出。导出的 [SVG](branding/icon.svg) 与 [PNG](branding/icon.png) 可用于项目介绍。
