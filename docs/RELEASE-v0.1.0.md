# 拾光清理 PhotoKeep v0.1.0

首个 Android 预发布版。保留 OneDrive 官方应用的自动备份，通过手机直接核对和清理对应云端照片，无需服务器。

## 下载与安装

下载附件 `PhotoKeep-0.1.0.apk`，支持 Android 11 及更新版本。附件 `SHA256SUMS.txt` 可核对安装包完整性，`APK-SIGNATURE.txt` 提供公开证书信息，`APP-REGISTRATION.txt` 提供本发布包的微软 Android 注册信息。

**安装后仍需要完成一次微软应用注册与授权。** 初版没有内置共享 client ID，不需要创建客户端密码。请参阅仓库中的 [中文连接教程](https://github.com/Pigbibi/OneDriveDeletionHelper/blob/main/docs/SETUP.zh-CN.md)。

## 初版功能

- 中文原生界面：总览、清理预览、连接与设置，暖白与墨绿配色。
- 管理多个手机内部存储照片目录，以及多个 OneDrive 照片目录与年月子目录。
- 不上传或覆盖照片；清理前核对云端完整内容、文件版本与目录范围，移入回收站。
- 手动预览、确认清理、保留文件、最近记录和 Wi-Fi 定期检查。
- 自动清理默认关闭，仅适用于系统明确标记为回收站、连续两次有效检查并满 24 小时的文件。

## 验证与限制

已通过 37 项自动化测试、发布构建、Android lint 和签名核验；在 Android 15 模拟器中检查了安装和主要界面。

**尚未完成 Android 真机与真实 OneDrive 账号的完整联调；不同设备和相册应用的行为仍需验证。请先使用测试照片，确认后再开启自动清理。**

手机直接消失的文件仍需人工确认；Google Photos 的云端删除或未留下 Android 回收站状态的删除，不能保证自动传播。历史云端多余照片、重复文件和无法明确关联的特殊格式将保留。当前只管理内部存储中系统可见的照片和视频，不支持 SD 卡和逻辑相册同步。

更新时直接覆盖安装，不要先卸载。本机对应记录和发布签名均影响后续使用；自行编译的调试 APK 通常不能覆盖这个发布包。
