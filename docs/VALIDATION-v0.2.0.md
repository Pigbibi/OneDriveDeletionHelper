# v0.2.0 验证范围

## 构建与自动化验证

- Java 17、Android SDK 37、Android Gradle Plugin 9.3.1 编译签名发布 APK；版本名 0.2.0，版本号 2，最低 Android 11，非调试包。
- 实际内置注册配置下，完整测试集共 50 项：48 项通过，2 项仅针对空配置的测试按条件跳过，无失败或错误。
- 另以空配置运行连接与 Android 集成测试：27 项通过，其中包含上述 2 项“未配置安装包不引导普通用户注册应用”的测试。
- 覆盖旧版配置保留、未配置安装采用内置连接、切换注册或账号时停止后台检查并清除旧关联、拒绝过期登录回调、无效输入保留表单与错误提示。原有删除保护测试继续通过。
- `lintRelease` 无错误；3 项提示为可用的新构建工具版本、最低系统版本下的冗余条件与文本国际化建议。新图标无 lint 提示。
- 明确传入空 Client ID 时，发布构建被 `verifyMicrosoftRegistration` 拒绝。此检查不能代替真实微软授权验证。
- APK Signature Scheme v2 验证通过，证书与 v0.1.0 相同；APK 中包含配置的公开 Client ID。

## 微软后台配置

已在 Microsoft Entra 中创建 PhotoKeep 应用，并逐项检查保存后的配置：

- 支持组织目录和个人 Microsoft 账号。
- Android 包名 `cn.lisiyi.photokeep` 与发布签名回调一致。
- Microsoft Graph 委托权限仅声明 `Files.ReadWrite`，移除默认且未使用的 `User.Read` 声明。
- 已保存项目主页、MIT 协议与隐私说明链接。
- 未创建客户端密码、应用程序权限或授予全组织管理员同意；尚未完成发布者验证。

## Android 15 模拟器

- 在已安装的 v0.1.0 中选择合成测试照片目录，再用同一签名的 v0.2.0 覆盖安装；安装成功，版本号变为 2，所选手机目录仍为 1 个。
- 正常字号下复核总览与设置，已更新仓库截图；设置显示高级连接入口和保留的合成测试目录。
- 360dp 屏幕、130% 字体下，新版总览显示“登录 OneDrive”，文字可读，超出屏幕的设置内容可滚动。
- 点击总览的“登录 OneDrive”后已调起 Chrome 浏览器，没有出现 Client ID 表单。模拟器的 Chrome 首次初始化未完成，尚未验证微软登录页面加载、授权完成和返回应用；不能把调起浏览器等同于登录成功。
- 图标提供矢量前景、独立背景与单色层；导出预览与 Android 系统启动画面中的圆形裁切均已检查，主体完整。
