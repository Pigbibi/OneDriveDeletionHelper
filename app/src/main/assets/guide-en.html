Getting Started with PhotoKeep

Keep the official OneDrive app for automatic backups. PhotoKeep only checks photo links and cleans up deleted items; it never uploads photos or changes year-month folders.

1. Sign in to OneDrive

Tap "Sign in to OneDrive", sign in with your account on Microsoft's official page, grant permission, and return to the app. Release packages include a default connection; ordinary users do not need to register a Microsoft app, enter a Client ID, or use a client secret.

Work or school accounts may require organization administrator approval. This project has not completed Microsoft publisher verification, so self-consent depends on your organization's policy.

Upgrading over an older build keeps your custom connection and existing photo links. To switch back to the default connection, open "Settings → Advanced connection settings → Restore default connection"; afterward you will need to sign in again, reselect OneDrive folders, and rebuild links.

Only users building from source or using their own app registration need "Advanced connection settings → Custom Client ID". View developer guide.

2. Select managed folders

Allow access to all photos, videos, and original media info; if only partial photo access is granted, the app pauses checks. Select internal storage folders such as Camera, Pictures, and Screenshots.

Add the matching OneDrive photo folders; you can choose multiple folders including subfolders. Phone folders do not need to match cloud year-month folders. Start with a dedicated test folder on your first run.

3. Build photo links

Connect to Wi-Fi and tap "Build initial links" on Overview. Local files are hashed locally; candidate links are paired with cloud items. Cloud originals are only downloaded to verify content right before recycling, so large videos take longer.

The first check never cleans up older extra files. Files with the same name and size but different content are never deleted; items with multiple possible matches are also kept.

4. Verify cleanup

Take a few test photos, wait for OneDrive to upload them, and build links. Delete one on your phone, then tap "Check photos now". Select and verify it in "Cleanup Preview", then confirm to move it to the OneDrive recycle bin.

Also test moving a photo, renaming it, keeping another identical copy, and revoking photo permissions to confirm nothing is deleted by mistake.

5. Scheduled checks & auto cleanup

You can schedule checks every 6 hours, 12 hours, or daily, running only on Wi-Fi when battery is not low. Allow notifications in app settings and adjust background or battery optimization limits as needed. Some devices also provide an auto-start toggle whose name varies by OS. Actual timing depends on OS scheduling.

Auto cleanup is off by default. When enabled, it only processes files explicitly marked as trashed by the phone OS across two consecutive valid checks spanning at least 24 hours. At most 10 files run per batch, and batches exceeding roughly 20% of linked files pause automatically (at most 1 when fewer than 5 links exist).

Files that simply disappear from the phone cannot be distinguished from moves, hiding, or storage freeing, so they always require manual confirmation. Deletions in Google Photos that do not appear in the Android OS trash follow the same rule.

Troubleshooting

Incomplete checks never treat missing data as deletions. When a recycle request has an uncertain outcome, auto cleanup pauses and never retries automatically; check OneDrive first, then choose "Keep & stop tracking" in Preview.

Install APK updates directly over the existing app instead of uninstalling first; uninstalling erases local links. Cloud files remain untouched. Only install packages signed with the same release key.
