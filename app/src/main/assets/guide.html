开始使用拾光清理

保留 OneDrive 官方应用的自动备份。拾光清理只检查照片对应关系和清理，不上传照片，也不改变年月目录。

1. 首次连接微软

这个开源初版需要你注册自己的微软应用。打开 Microsoft Entra 管理中心，进入“应用注册 → 新注册”。如果账号没有创建应用的权限，需要先解决微软账号的注册权限，不能跳过此步骤。

名称填写 PhotoKeep；支持的账户类型选择“任何组织目录中的账户和个人 Microsoft 账户”。记录 Application (client) ID。

在应用注册的“身份验证 → 添加平台”中选择 Android。回到拾光清理的“设置 → 首次连接设置”，复制包名和签名哈希，填入微软页面并保存。

在 API 权限中添加 Microsoft Graph 的“委托权限 → Files.ReadWrite”。不需要创建客户端密码，不要把客户端密码填入手机或代码。

回到拾光清理，填入公开的 Application (client) ID，保存后点“登录 OneDrive”，在微软官方页面完成授权。

2. 选择管理目录

允许访问全部照片和视频及原始媒体信息；如果只授权部分照片，应用会暂停检查。选择手机内部存储的相机、Pictures、截图等目录。

添加对应的 OneDrive 照片文件夹，可选择多个目录并包含子目录。手机目录与云端年月目录不必相同。初次建议使用专门的测试目录。

3. 建立对应关系

连接 Wi-Fi，点击总览中的“建立首次对应关系”。手机文件会在本地计算内容校验值；云端先建立候选关联。真正清理前才读取云端原文件核对内容，视频较大时耗时较长。

首次检查不会清理历史多余文件。同名、同大小但内容不同的文件不会删除；存在多个可能匹配时也会保留。

4. 检查删除

先拍几张测试照片，等待 OneDrive 完成上传并建立对应关系。删除其中一张，再点击“立即检查照片”。到“清理预览”勾选并核对，确认后移入 OneDrive 回收站。

再测试移动照片、改名、保留另一份相同副本和撤销照片权限，确认不会误删。初版尚未完成 Android 真机与真实 OneDrive 账号的完整联调，不同设备和相册应用的行为仍需验证。

5. 定期检查和自动清理

可以设置每 6 小时、12 小时或每天检查，仅 Wi-Fi 且电量不低时运行。在手机的应用设置中允许通知，按需调整后台运行或电池优化限制。部分系统另有自启动选项，菜单名称因设备及系统版本而异。检查时间会受系统调度影响。

自动清理默认关闭。开启后仅处理手机系统明确标记为回收站、连续两次有效检查且满 24 小时的文件。一次最多 10 个，超过约 20% 关联文件时也会暂停（不足 5 个关联时最多 1 个）。

手机中直接消失的文件无法确定是主动删除、移动、隐藏还是释放空间，因此仍需手动确认。Google Photos 的删除若没有显示为 Android 系统回收站状态，也按这个规则处理。

遇到问题

检查未完成时不会把缺少数据当成删除。清理请求的结果无法确认时会暂停自动清理，不会自动重试；请到 OneDrive 核对，再在预览中选择保留并停止跟踪。

更新 APK 时直接覆盖安装，不要先卸载；卸载会丢失本机对应记录。云端文件保持原样。仅使用同一发布签名的安装包。
